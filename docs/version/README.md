# Numbered product versions

This folder is the current **core product version** and the queue for later numbered work. Standalone add-ons (terminal, compaction, …) live under [`features/`](../features/README.md), not here.

| Path | Role |
| --- | --- |
| [`v3/`](./v3/README.md) | V3 — Change Control and Recovery product, plan, and work logs |
| [`roadmap-vnext.md`](./roadmap-vnext.md) | Independently promotable later phases |
| [`research-backlog.md`](./research-backlog.md) | Unpromoted core-product research; not add-ons or promises |

Closed versions stay in the [`archive`](../archive/README.md). Do not reopen v1 or v2 contracts here.

When a later numbered version is promoted, add `version/v4/` (product + implementation plan) and leave v3 in place until it is archived.
