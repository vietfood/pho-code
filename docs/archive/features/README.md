# Retired feature archive

This directory is reserved for standalone add-ons that were retired, superseded, or abandoned.

Move a feature here with its product contract, implementation plan, work logs, acceptance or abandonment record, and a pointer to its replacement when one exists. Completion alone is not a reason to archive a feature: accepted add-ons that remain part of Pho Code stay under [`../../features/`](../../features/README.md).
