# Git change tracking logs

Dated execution evidence for the git change tracking add-on. The
[product](../product.md) and [implementation plan](../implementation-plan.md)
are read-mostly contracts; this folder carries dated work, measurements,
failures, corrections, owner feedback, blockers, and handoffs.

One log file per bounded slice, issue, or feedback thread. Do not make
parallel agents append to one shared journal.
